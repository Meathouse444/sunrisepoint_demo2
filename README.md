# Sunrise Point · 2023 vision demo

A second website concept for The Inn at Sunrise Point, built from Ryan's 2023
redesign brief ("Sunrise Point Questions From Heather"): the Gregøri Webflow
hotel template's layout, the inn's brand guide colors (sandy gold, white, black)
and fonts (Georgia, Open Sans), and the sitemap from that doc.

Compare it with the newer concept in `sunrise-point-demo`.

## Make the video from your phone

1. Open the **Code** tab in the Claude app and pick this repo. (1 min)
2. Type: `Follow PROMPT.md and make the demo video.` (20–30 min, hands-off)
3. Open the GitHub links it replies with to watch and download. (5 min)

## Look at the pages yourself

Run `python3 -m http.server` inside `site/` and open http://localhost:8000.
